# Contributing

Thanks for your interest! StoryMode is developed in a private repository and
published here as a snapshot, so this repository doesn't accept pull
requests: they're closed automatically, and each release replaces its
contents.

You're welcome to fork it and change it however you like within the
[license](LICENSE.md).

Bug reports and ideas are welcome, though:
- 🐞 [Report a bug](https://github.com/sakhnenko/storymode-community/issues/new?template=bug_report.yml)
- 💡 [Share an idea](https://github.com/sakhnenko/storymode-community/discussions/categories/ideas)
- 🙋 [Ask for setup help](https://github.com/sakhnenko/storymode-community/discussions/categories/q-a)
- 🔒 Security problems: [report them privately](https://github.com/sakhnenko/storymode-community/security/advisories/new) (see [SECURITY.md](SECURITY.md))
